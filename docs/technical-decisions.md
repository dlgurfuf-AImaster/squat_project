### Database Selection: MariaDB to PostgreSQL

**Initial Choice — MariaDB**

SquatMate의 초기 개발 단계에서는 학교에서 학습한 경험과 익숙한 개발 환경을 바탕으로 MariaDB를 선택했다. MySQL과 높은 호환성을 갖춘 관계형 데이터베이스로, 사용자 정보와 운동 기록을 관리하는 프로젝트의 초기 요구사항을 충족하기에 충분하다고 판단했다.

**Migration — PostgreSQL**

온라인 배포 환경을 구성하는 과정에서 클라우드 데이터베이스의 제공 방식과 배포 환경과의 적합성을 고려해 PostgreSQL로 전환했다. 특히 Supabase에서 PostgreSQL 데이터베이스를 제공한다는 점이 선택에 영향을 주었다.

**Why PostgreSQL?**

MariaDB와 PostgreSQL은 모두 관계형 데이터베이스이므로, 기존에 구현한 사용자 관리, 운동 기록 저장, 백엔드 API 등의 핵심 구조를 유지하면서 데이터베이스를 전환하는 방향을 선택할 수 있었다. 이를 통해 데이터베이스 전환에 따른 시스템 변경 범위를 관리하면서 로컬 개발 환경과 배포 환경을 PostgreSQL 기반으로 통일하고자 했다.

이번 전환은 특정 데이터베이스가 다른 데이터베이스보다 절대적으로 우수하다는 판단보다는, 기존 시스템의 구조와 실제 배포 환경을 함께 고려한 기술적 의사결정이었다.


**Flutter · Dart**

SquatMate의 UI 구성, BLE 센서 연동, 실시간 데이터 처리 및 상태 관리 요구사항을 충족할 수 있다고 판단해 Flutter를 선택했다. 또한 공통 코드베이스를 활용해 Android와 iOS 앱을 개발할 수 있다는 점을 고려했으며, 프로젝트 범위에서 다른 프레임워크로 전환해야 할 뚜렷한 필요성을 발견하지 못했다.
