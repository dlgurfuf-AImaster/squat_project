## 🛠️ 기술 스택 및 선정 이유

| 구분 | 기술 | 선정 이유 |
|---|---|---|
| 모바일 앱 | Flutter · Dart | 하나의 코드베이스로 Android 앱 구현 |
| 백엔드 | Java 21 · Spring Boot | REST API 및 비즈니스 로직 구현 |
| 데이터베이스 | PostgreSQL | 관계형 데이터 관리 및 배포 환경과의 일관성 확보 |
| 로컬 저장소 | SQLite | 운동 기록의 로컬 저장 및 오프라인 데이터 관리 |
| 인증 | JWT | 로그인 기반 사용자 인증 및 API 접근 제어 |
| AI 코칭 | Gemini API | 운동 기록을 바탕으로 맞춤형 피드백 제공 |
| 배포 | Render · Supabase | 백엔드 애플리케이션 및 PostgreSQL 데이터베이스 배포 |

> **기술 선택 및 데이터베이스 전환 과정:** [기술 의사결정 문서](./docs/technical-decisions.md)
